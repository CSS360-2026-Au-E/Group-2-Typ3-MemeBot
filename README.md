# typ3 — CSS 360 Discord Bot

## About
Our group project for CSS 360, Autumn 2026.
We are using the course's JavaScript Discord Welcome
MemeBot example as our starting point.

## Current Status
We are in the initial setup and planning stage,
organizing our GitHub and Discord environments
and brainstorming bot features. Custom features
have not been implemented yet.
